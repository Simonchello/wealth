    Методология и источники

    Источники данных: World Inequality Database (WID.world) — пороги перцентилей дохода для крупнейших экономик; World Bank Open Data — средний доход (GDP per capita) и коэффициент Джини; OECD Income Distribution Database — для стран ОЭСР.

    Методология. Где доступны прямые данные WID — используется кусочно-логлинейная интерполяция между порогами P10/P25/P50/P75/P90/P95/P99. Для остальных стран распределение дохода аппроксимируется логнормальной моделью с параметрами, выведенными из среднего дохода и коэффициента Джини (стандартный подход в экономике неравенства). Для союзов и регионов распределения отдельных стран взвешиваются по численности взрослого населения.

    Метки источников на каждом результате: «WID.world» / «World Bank» — реальные опубликованные данные; «log-normal model» — логнормальная аппроксимация на основе Джини; «AI predicted» — данных нет в открытом доступе, оценка приближённая.

    Все цифры приведены к годовому доходу в долларах США (номинальные, не PPP), последний доступный год (как правило, 2021–2023). Это упрощённая модель — она не учитывает региональные различия внутри стран, налоги, стоимость жизни и теневую экономику.

    Список «Кто богаче». Поимённый список появляется на карточке, только когда вы попадаете в очень верхние ряды (top < 0,5%). Источник — Forbes 2026 World's Billionaires List (мартовский релиз + real-time обновления, проверено в мае 2026). В списке указан общий капитал, а не годовой доход — публичных данных по личной годовой зарплате конкретных людей по миру не существует.
