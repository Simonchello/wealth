# Где вы стоите в мире? — калькулятор перцентиля дохода

Статический одностраничный сайт. Вводите свою зарплату — узнаёте, в какой
топ-процент вы попадаете в любой стране, союзе или регионе. Все суммы — в
долларах США. Интерфейс на английском по умолчанию, есть переключатель `EN · RU`
в правом верхнем углу.

---

## Как запустить локально

Сборки нет. Никаких `npm install`. Просто отдайте папку через любой HTTP-сервер
и откройте в браузере.

### Вариант 1 — Python (есть на любом Mac/Linux, на Windows ставится за 1 клик)

В терминале из папки с проектом:

```bash
python3 -m http.server 8000
```

Откройте в браузере: **<http://localhost:8000>**

Чтобы остановить — `Ctrl+C` в терминале.

### Вариант 2 — Node.js

Если у вас стоит Node:

```bash
npx serve .
```

…или…

```bash
npx http-server . -p 8000
```

(Если `npx` спросит, можно ли скачать пакет — соглашайтесь.)

### Вариант 3 — двойной клик по `index.html`

В Chrome обычно работает, но карта мира **может не загрузиться**: браузеры
блокируют сетевые запросы для страниц, открытых через `file://`. Поиск по
странам и кнопки групп будут работать, но интерактивная карта — нет.
**Лучше всё-таки поднять локальный сервер** (Вариант 1 или 2).

> **Зачем нужен сервер?** Контуры стран на карте подгружаются с CDN
> ([world-atlas TopoJSON](https://cdn.jsdelivr.net/npm/world-atlas@2/)). Этот
> запрос работает только если страница отдана по `http://` или `https://`.
> Сам сайт остаётся статическим — никакого бэкенда нет.

## Как выложить в интернет

Поскольку это статика, подойдёт любой бесплатный хостинг.

| Хостинг        | Как                                                                |
|----------------|--------------------------------------------------------------------|
| GitHub Pages   | Запушить в публичный репо → Settings → Pages → Branch: `main` / `/` |
| Netlify        | Drag-and-drop папки проекта на [app.netlify.com/drop](https://app.netlify.com/drop) |
| Vercel         | `vercel` из папки (после `npm i -g vercel`)                         |
| Cloudflare Pages | Подключить репо в дашборде                                        |
| Свой сервер    | Положить файлы в любую папку, отдаваемую nginx/Apache               |

Никакой настройки не требуется — нет переменных окружения, нет билд-команды.

## Что в папке

```
.
├── index.html      # Разметка страницы и языковой переключатель
├── styles.css      # Тёмная тема + золотой акцент
├── i18n.js         # Словарь EN/RU и хелперы локализации
├── data.js         # 176 стран + 15 групп + ~60 миллиардеров (Forbes 2026)
├── app.js          # Статистика, карта, рендеринг результатов
└── README.md       # Этот файл
```

Все скрипты подгружаются через `<script src=…>` в `index.html` —
порядок не меняйте.

## Что использует сайт из интернета

При первом открытии браузер подтягивает три внешние ресурса с CDN:

- [D3 v7](https://d3js.org/) — проекция и рендер карты
- [TopoJSON Client](https://github.com/topojson/topojson-client) — распаковка карты
- [Google Fonts](https://fonts.google.com/) — Inter и Playfair Display

После первой загрузки эти файлы кэшируются. Если хотите 100% офлайн — скачайте
их вручную и поправьте `<script>` / `<link>` теги в `index.html`.

## Часто задаваемые

**Карта не появилась — почему?**
Открыли `index.html` через `file://`. Поднимите локальный сервер (см. выше) или
выложите на хостинг.

**Цифры по перцентилям отличаются от других калькуляторов.**
Большинство публичных калькуляторов используют PPP (Purchasing Power Parity).
Здесь — номинальные доллары. Поэтому при сравнении со странами с низкой
стоимостью жизни ваш номинальный доход будет выглядеть «выше» по перцентилю.

**Хочу добавить свою страну.**
Добавьте запись в `COUNTRIES` в `data.js`. Минимум: `name`, `nameEn`, `iso`
(числовой ISO 3166-1 — нужен для карты), `population`, `meanIncome` (USD/год),
`gini`. Можно опционально передать `percentiles: { 10: …, 50: …, 90: …, 99: … }`
— тогда модель использует прямую интерполяцию, а не log-normal.

**Хочу русский по умолчанию.**
Откройте `i18n.js` и поменяйте дефолт в верхней строке:
`return 'en';` → `return 'ru';`. Или просто кликните `RU` один раз — выбор
запомнится в localStorage.
